# Agency.ai - Responsive Agency Website

A fully functional, responsive agency website built with React and Tailwind CSS. This project showcases component-based architecture, state management, and modern web design practices.

## 🎯 Project Overview

**Agency.ai** is a professional website for a digital agency that specializes in turning imagination into digital impact. The site features a clean, modern design with smooth navigation, service offerings, portfolio showcase, team highlights, and a contact section.

### Key Features

- ✨ **Fully Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern UI/UX** — Clean, professional interface with intuitive navigation
- ⚛️ **Component-Based Architecture** — Modular, reusable React components
- 🎭 **State Management** — Effective prop passing and component state handling
- 🚀 **Fast & Lightweight** — Built with Vite for optimal performance
- 🌙 **Theme Toggle** — Light/dark theme support for better user experience

## 🛠️ Tech Stack

- **React** — JavaScript library for building user interfaces
- **Tailwind CSS** — Utility-first CSS framework for styling
- **Vite** — Next-generation frontend build tool
- **JavaScript ES6+** — Modern JavaScript features

## 📂 Project Structure

```
src/
├── components/          # Reusable React components
│   ├── Navbar.jsx      # Navigation bar component
│   ├── Hero.jsx        # Hero section with call-to-action
│   ├── Services.jsx    # Service offerings display
│   ├── Ourwork.jsx     # Portfolio/latest work showcase
│   ├── Teams.jsx       # Team members section
│   ├── ServiceCard.jsx # Reusable service card component
│   ├── Footer.jsx      # Footer section
│   ├── Contact.jsx     # Contact form section
│   ├── Title.jsx       # Reusable title component
│   └── TrustedBy.jsx   # Client/company logos section
├── assets/             # Images, icons, and other media
├── App.jsx             # Main app component
├── index.css           # Global styles
├── main.jsx            # Entry point
└── ServiceCard.jsx     # Service card component

```

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/agency-ai.git
   cd agency-ai
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Enter your Email API FROM ANY WEBSITE LIKE FROM WEB3FORMS**
  

4. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

### Build for Production

```bash
npm run build
```

The optimized production build will be created in the `dist/` folder.

## 📖 Component Overview

### **Navbar**
Navigation bar with logo and menu links. Sticky positioning for easy access.

### **Hero**
Hero section with compelling headline, subheading, and call-to-action button.

### **Services**
Displays agency services with icons and descriptions (Advertising, etc.).

### **ServiceCard**
Reusable component for displaying individual service information.

### **Our Work**
Portfolio section showcasing latest projects (Mobile App Marketing, Dashboard Management, Fitness App Promotion).

### **Teams**
Team member profiles with images and roles.

### **Contact**
Contact form for inquiries with email input field.

### **Footer**
Footer with company info, links, and social media connections.

### **ThemeToggleBtn**
Theme switcher component for light/dark mode toggle.

### **TrustedBy**
Section displaying companies/clients that trust the agency.

## 🔄 State Management

State is managed through:
- **Lifting state up** — Passing state from parent to child components
- **Props** — Communicating between components
- **Local component state** — Managing individual component behavior

## 📱 Responsiveness

The website is fully responsive using Tailwind CSS breakpoints:
- Mobile-first approach
- Flexible grid and flexbox layouts
- Responsive typography and spacing
- Mobile-optimized navigation
